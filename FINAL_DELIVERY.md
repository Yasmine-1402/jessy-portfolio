## 🆘 Quick Help

### Problem: Dependencies not installing
**Solution**: Make sure Node.js is installed
- Download from nodejs.org
- Check: `node --version`

### Problem: Port 3000 in use
**Solution**: 
```powershell
npm run dev -- -p 3001
```

### Problem: Styles not applying
**Solution**: 
```powershell
npm run build
```

### Problem: Build fails
**Solution**:
```powershell
Remove-Item -Recurse -Force node_modules
npm install
npm run build
```
