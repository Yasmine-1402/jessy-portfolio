# Yasmine's Premium Portfolio

A modern, elegant, and fully responsive portfolio website built with Next.js 15, TypeScript, Tailwind CSS, and Framer Motion.

## Features

✨ **Modern Design**
- Premium dark mode with glassmorphism effects
- Smooth animations and transitions
- Responsive design for all devices
- Elegant gradient accents

🚀 **Performance Optimized**
- Next.js 15 with App Router
- TypeScript for type safety
- Optimized images and lazy loading
- Fast page loads and smooth interactions

📱 **Fully Responsive**
- Mobile-first design
- Desktop, tablet, and mobile support
- Touch-friendly interactions
- Adaptive layouts

🎯 **SEO Optimized**
- Meta tags and descriptions
- Open Graph support
- Twitter card integration
- Semantic HTML

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
# Navigate to project directory
cd portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm start` - Start production server
- `npm run lint` - Run ESLint

## Customization

### Update Content
Edit `data/content.ts` to customize:
- Profile information
- Education details
- Experience and projects
- Skills and expertise
- Certifications

### Customize Colors
Edit `tailwind.config.ts` to modify:
- Color palette
- Animation timings
- Typography
- Spacing

### Update Styles
Edit `app/globals.css` for:
- Custom animations
- Theme adjustments
- Component styling
