## 🎯 How to Use

### Step 1: Install & Run (2 minutes)
```bash
cd portfolio
npm install
npm run dev
```
Visit `http://localhost:3000` ✅

### Step 2: Customize Content (5 minutes)
Edit `data/content.ts` to update:
- Profile information
- Projects and links
- Skills and expertise
- Experience details

### Step 3: Test & Preview (5 minutes)
- Check on mobile devices
- Test all links and forms
- Verify animations

### Step 4: Deploy (2 minutes)
```bash
# Option A: Vercel (Recommended)
git push to GitHub → Auto-deploy on Vercel

# Option B: Build locally
npm run build
npm start
```
